# 内容与素材来源

## 主要来源

1. `SIGA-PR/JointLight_微信公众号宣传稿.docx`（本次读取的最新版本）：组织方法、中文表述、方法与数据插图、GitHub 地址。
2. 用户提供的 JointLight 论文 PDF：作者顺序与单位、方法细节、训练与测试设置、定量结果和引用信息。
3. `SIGA-PR` 下四段 MP4：原有选择和剪辑均保留，网页中按静态、动态、辐照度、更多结果分类展示。
4. 概览图、联合训练图、推理图和数据图均直接从论文原版 PDF 截取，保留原始英文标注。辐照度差距示意使用用户提供的三张无标注原始图片，在网页中并排显示并采用英文标签。

## 页面数据口径

- 合成训练数据：6,800 个场景、68,000 条视频、30 个环境、60 个角色、600 段身体动画、821 张 HDR 环境贴图。
- SynthStatic：40 个动态场景，目标照明固定。
- SynthDynamic：10 个动态场景，目标照明旋转。
- 实验表格选列 DiffusionRenderer、UniRelight、JointLight。全部基线见论文 Table 1、Table 2；没有宣称静态测试的 SSIM 最优。
- HumanOLAT 是未参与训练的真实采集静态图像评估；采用前景掩膜，不作逐颜色通道缩放。
- 消融实验使用统一 6K 步训练预算，与主结果单独说明；域匹配在最后 2K 步应用。
- 用户研究：13 名参与者、15 个真实视频案例，5 分制；视觉质量 3.98、光照保真度 4.53。
- 运行时间：单 GPU、81 帧、832 × 480、50 步采样，完整流程约 223 秒。
- “仅合成数据”指重光照任务微调，页面没有将其扩展为基础模型从零训练。
